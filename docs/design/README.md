# Дизайн-референсы трекера

Утверждённые макеты (светлая и тёмная тема), на основе которых строится
фронтенд (раздел 15 ТЗ, план — `docs/implementation_plan.md`, Этап 13).

- `references/` — статичные HTML-макеты как есть (дашборд/страница задачи ×
  desktop/планшет/мобильная × светлая/тёмная тема), 10 файлов. Открываются
  прямо в браузере — референс по layout, компонентам и адаптивности.
- `../../frontend/src/styles/tokens.css` — те же цвета/шрифты уже как
  реальные CSS-переменные для фронтенда (`:root` / `[data-theme="dark"]`).

Ключевые решения макета:
- Сайдбар слева с подписанными разделами (раздел 15.1 ТЗ), фирменный знак —
  восходящие узлы пайплайна (доменная метафора трекера), не дженерик-градиент.
- Задачи на дашборде — карточками с рамкой по цвету статуса (не списком) и
  кнопками запуск/стоп/таймер прямо на карточке.
- Страница задачи — две зоны (данные / диалог), см. `task-*-desktop.html`.
- Переключатель темы — компактный sun/moon-тумблер внизу сайдбара.
