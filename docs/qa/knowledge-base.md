# Проверка базы знаний

## Окружение

Локальный Tracker с изолированной PostgreSQL и хранилищем файлов. Интерфейс проверяется в Chrome: 1440×1000, 768×1024, 390×844, 320×740, 844×390. У каждого сценария собственный раздел.

## Автоматические проверки

- Backend: API, права ролей, версии, конфликты, дерево путей, перенос/восстановление папок, снимок прав агента, хранилище, воркер сессии и резервные копии.
- Frontend: выбор и создание папок, загрузка в выбранную папку, переключение корзины и сохранение открытой исторической версии с проверкой текущей версии.
- Отдельный реальный Claude Code через шлюз моделей: чтение списка, создание нового файла и повторное чтение через MCP; проверка связи версии с задачей.
- Отдельный Docker-контейнер: чтение подключённых файлов и отказ прямой записи.

Результаты ручного и браузерного прогона фиксируются после завершения проверки; эта таблица описывает ожидаемое поведение и не означает, что каждый сценарий уже выполнен вручную.

## Результат прогона 14.11.2026

- Основные UI-сценарии KB-02, KB-06, KB-08, KB-09, KB-11, KB-12, KB-14, KB-22 прошли на всех пяти разрешениях. При конфликте текст пользователя сохраняется; перечитывание обновляет также номер версии.
- KB-01 и прокрутка меню проверены на 1440×1000, 1440×600, 768×1024, 390×844, 320×740 и 844×390: пункт базы знаний непосредственно перед шаблонами, профиль и нижние пункты достижимы прокруткой.
- KB-04 и KB-05 проверены в браузере под обычным пользователем на пяти разрешениях: скрытого раздела нет, редактор выключен, кнопок записи и создания разделов нет.
- KB-10, KB-13, KB-15, KB-19 дополнительно прошли в браузере: восстановление старого содержимого новой версией, побайтовое совпадение загруженного и скачанного бинарного файла, поиск по содержимому, отмена и подтверждение ухода с несохранённым текстом.
- KB-07 выполнен настоящим Claude Code через шлюз моделей; создан новый файл и проверена связь версии с задачей. KB-18 выполнен в настоящем Docker-контейнере: чтение разрешено, прямая запись отклонена.
- Права, запрещённые пути, конфликт версий, история, перенос и восстановление папки, снимок прав сессии покрыты backend-тестами. Восстановление резервных копий проверяется существующими автоматическими тестами подсистемы; отдельное восстановление всего сервера вручную не выполнялось.
- Полный backend-прогон: 2845 тестов, покрытие services 94,33%. Полный frontend-прогон: 1010 тестов. После последних исправлений повторно прошли 143 затронутых backend-теста, 60 тестов воркера и 14 frontend-тестов страницы и навигации. Линтеры, проверка типов и production-сборка прошли.

Скриншоты и машинные отчёты локального браузерного прогона: `/tmp/knowledge-ui-results/` (временные артефакты машины разработчика, в Git не включаются).
